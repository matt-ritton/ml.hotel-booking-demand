# 🏨 Hotel Booking Cancellation Analysis and Prediction

Hotel booking cancellation analysis and prediction with GLM, LDA and Random Forest. This project was developed in 2026 for the Introduction to Statistical Learning course, as a way to put into practice the knowledge acquired throughout the Master's program in Mathematical and Computer Modeling.

## About this repository

The notebook contains a didactic step-by-step methodology applied to the [Hotel Booking Demand dataset](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand/data), which records bookings at a city hotel and a resort hotel in Portugal. The goal was to predict whether a booking will be canceled before check-in and to discuss the results obtained. Preprocessing covered the treatment of categorical variables, the removal of inconsistent or rare records and the exclusion of variables that could cause data leakage, followed by an exploratory analysis of the main factors associated with cancellations. The models used were based on Logistic Regression, Linear Discriminant Analysis (LDA) and Random Forest, compared against a naive baseline using accuracy, sensitivity, specificity and precision. For more information about the results obtained, please refer to the Jupyter notebook.
